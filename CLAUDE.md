## Commands

- `npm run dev` — start the dev server (Turbopack). This is the only way the app should be run locally.
- `npm run build` — production build.
- `npm run start` — run the production build.
- `npm run lint` — ESLint (flat config, `eslint-config-next` core-web-vitals + typescript rules).

No test framework is configured yet.

## Architecture

This is **CallDesk**, an AI voice-agent app for travel advisors (calls hotels to negotiate rates/amenities/upgrades, then produces structured notes). Product scope, feature list, user flow, and the full planned REST/SSE API contract live in [mvp.md](mvp.md) — read it before adding backend routes or frontend data fetching so new work matches the agreed shapes (`/api/calls`, `/api/calls/:callId`, `/api/calls/:callId/stream`).

- **Next.js 16 App Router**, source rooted at `src/app`. This Next.js version has breaking API/convention changes vs. training data — see `@AGENTS.md` above and check `node_modules/next/dist/docs/` before using unfamiliar APIs.
- **Route Handlers** (backend endpoints) go in `src/app/api/**/route.ts`, exporting `GET`/`POST`/etc. Type dynamic params with the generated `RouteContext<'/path/[id]'>` helper rather than hand-writing param types; page/layout props similarly use generated `PageProps<'/route'>` / `LayoutProps<'/route'>` (see `src/app/layout.tsx` for an example). These types are generated by `next dev`/`next build`/`next typegen`.
- **Styling**: Tailwind v4, CSS-based config in `src/app/globals.css` (no `tailwind.config.*` file).
- **UI components**: shadcn, configured via `components.json` — style `base-nova`, **Base UI** primitives (not Radix), `lucide-react` icons. Add components with `npx shadcn@latest add <component>`; they land in `src/components/ui`. Import aliases: `@/components`, `@/components/ui`, `@/lib`, `@/hooks` all resolve under `src/` (see `tsconfig.json` path alias `@/*` → `./src/*`).
- No database or auth yet — MVP plan calls for in-memory server-side state only.
